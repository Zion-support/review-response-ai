# Review Response AI

**Zion Review Response AI** — on-brand review responses with sentiment-aware drafting, triage and escalation.

> Part of the **Zion AI App Network** — see [ZION_APP_NETWORK.md](./ZION_APP_NETWORK.md) for the full mesh of interlinked apps.

Live app: https://ziontechgroup.com/review-response-ai/

## ✨ Features
- **On-brand drafting** — replies in your voice, tuned per platform (Google, Trustpilot, marketplaces).
- **Sentiment triage** — urgent negatives surfaced first, with escalation to a human when needed.
- **Theme extraction** — turns reviews into product/ops insights (recurring complaints & praise).
- **Multi-language** — responds in the reviewer's language automatically.
- **Rating recovery tracking** — measures rating and conversion impact of responses.
